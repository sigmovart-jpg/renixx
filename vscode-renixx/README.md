# Renixx Language Support for VS Code

Syntax highlighting, snippets, and language configuration for the **Renixx** programming language.

## Features
- Syntax highlighting for `.rn` files
- Comment toggling (`//`, `/* */`)
- Bracket matching and auto-closing
- Indentation rules
- Code snippets for common constructs

## Installation
Install from the VS Code Marketplace (search "Renixx") or install the `.vsix` manually:
```
code --install-extension renixx-1.0.0.vsix
```
