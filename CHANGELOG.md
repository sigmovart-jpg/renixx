# Changelog

## 1.0.0 (2026-10-26)

Initial release of Renixx.

- Lexer, parser, AST interpreter
- Variables, functions, lambdas, closures, classes, inheritance
- Control flow: if/else, while, for, match
- Exception handling
- Standard library: math, random, time, json, os, fs
- String interpolation
- Module imports
- CLI: run, repl, check, version
- Web playground (Pyodide)
- Documentation: spec, grammar, tutorial
- Test suite
